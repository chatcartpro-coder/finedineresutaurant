How it works

When a customer confirms a delivery order, the system automatically messages an active agent with the order details (items, total, customer phone, delivery address/map link). The agent replies:

  • PACKED once the kitchen has it ready
  • PICKED once they've collected it
  • DELIVERED once it's dropped off

Each reply updates the order's status here and can notify the customer.
